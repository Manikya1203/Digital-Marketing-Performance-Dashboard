# 📊 Digital Marketing Performance Dashboard | Excel

<img width="1852" height="661" alt="Digital_Marketing_Performance_Dashboard" src="https://github.com/user-attachments/assets/3b0b29be-0633-4db9-bdd4-fcb050a20f8c" />


An interactive Excel dashboard analyzing **$8.3M in digital marketing spend** across Google Ads, Facebook Ads & Display Ads. Built using **Pivot Tables & Charts** with slicers for dynamic filtering. Uncovers key insights on CTR, CPA, Conversions & Monthly Spend trends.

---

## 🚀 Project Overview

This dashboard was built entirely in **Microsoft Excel** to analyze and visualize digital marketing performance data across multiple platforms and quarters.

---

## 📌 Key Metrics Tracked

| Metric | Value |
|---|---|
| 💰 Total Spend | $8,337,817 |
| 👁️ Impressions | 421,230,481 |
| 🖱️ Total Clicks | 7,158,196 |
| ✅ Conversions | 434,423 |
| 📉 Avg CTR % | 1.70% |
| 💲 Avg CPC | $7.63 |
| 🎯 Avg CPA | $235.54 |

---

## 🔍 Key Insights

- 📅 **October** had the **peak spend at $812K** — highest in Q4
- 🥇 **Google Ads dominates conversions at 57%** of total
- 📈 **Google Ads CTR (2.76%)** is **3x better** than Display Ads
- ⚠️ **Display Ads has the highest CPA ($549)** — least cost efficient

---

## 🛠️ Tools & Features Used

- ✔️ Microsoft Excel
- ✔️ Pivot Tables
- ✔️ Pivot Charts
- ✔️ Interactive Slicers (Platform + Quarter)
- ✔️ KPI Summary Cards
- ✔️ Conditional Formatting
- ✔️ Dark Theme Dashboard Design

---

## 📊 Dashboard Components

- **7 KPI Cards** — Total Spend, Impressions, Clicks, Conversions, CTR, CPC, CPA
- **Monthly Spend Trend** — Line chart with peak highlight
- **CPA by Platform** — Bar chart comparison
- **CTR by Platform** — Bar chart comparison
- **Conversions by Platform** — Horizontal bar chart
- **Spend Share by Platform** — Pie chart with % labels
- **Interactive Slicers** — Filter by Platform & Quarter
